## 3. 口径与方法学边界

- **公开脚本口径**（可复现）：`node scripts/measure.mjs <session.jsonl>` 按 **JSONL 事件索引三等分**为早/中/晚；
  `tools` 与各段工具数均**不含 `mark_task`**（标定单列）；`read_image` 计**调用次数**（≠截图产出总数）；
  `redteam` 只计 `redteam_verdict` 调用（≠通过裁决）。该口径由 `node scripts/measure.mjs --selftest`
  与 `scripts/measure.test.mjs` 固定（段内工具数之和 = `tools`）。
- **本表口径 ≠ 脚本口径**：A/B/C 的早/中/晚（原文档亦称"首/中/末小类"）来自**作者历史逐小类统计**
  （小类=焦点注入→打卡），该切分**未在公开脚本中实现**；C 行实际只有总量，没有分段值。
- **因此**：本表**不能**用 `scripts/measure.mjs` 复算；且 A（分段）与 C（未分段）不是同一口径的对照，
  不足以证明"协议链验证投入全程无衰减"。
- **复算前提**：原始会话 JSONL（未随仓库发布）+ 与小类口径一致的统计实现（未提供）。

## 5. 来源与边界

- 数字来源：DATA.md（三会话指标表+懈怠强度表）；会话 ID 于列内标注。
- 边界：三会话**任务细节不同**（花/便利店/街区），"同型"指同为 3D 视觉场景类——对比是
  **行为模式**对比（验证勤勉度/完成模式），非效果评分对比；"3D"是任务类型，不是可度量指标。
- 复算：仅对**自己持有**的会话导出文件运行 `scripts/measure.mjs`，可复核事件级计数与事件索引三段；
  本表的历史逐小类数字不可由此脚本复算。
